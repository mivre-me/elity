        ล้างประวัติแชตทั้งหมด?

        เสียงคุณภาพสูง (Google)

        เสียงไทยธรรมชาติ มีทั้งชายและหญิง อ่านต่อได้แม้ปิดจอหรือปิดแอพ ใช้ฟรีเดือนละ 1-4 ล้านตัวอักษร ถ้าไม่มีเน็ตจะใช้เสียงในเครื่องแทน

        วิธีสร้าง key
        1. เปิด console.cloud.google.com → สร้างโปรเจกต์ใหม่ชื่อ Elity
        2. ค้นหา Cloud Text-to-Speech API → กด Enable (ต้องผูกบัตรครั้งแรก แต่ใช้ในโควตาฟรีไม่เสียเงิน)
        3. APIs & Services → Credentials → Create credentials → API key
        4. กด Edit key: Application restrictions เลือก Websites ใส่ mivre-me.github.io/* และ API restrictions เลือก Cloud Text-to-Speech API → Save
        5. คัดลอก key มาวางที่นี่ แล้วกดบันทึกและทดสอบ

        เสียงอ่าน

        ส่งประกาศเข้า Google Sheet

        ทุกประกาศที่เก็บใน Elity จะส่งสำเนาเข้าชีต Elity Brain ด้วย เปิดดูในชีตได้เหมือน Elity ตัวแรก (สำเนาในชีตไม่ได้เข้ารหัส) โน้ตกับแชตไม่ถูกส่ง

        เอาลิงก์กับรหัสลับจากไหน
        1. เปิดแอพ Elity ตัวเก่า (ไอคอนตัว E สีส้ม) → ตั้งค่า
        2. คัดลอกลิงก์ Apps Script มาวางช่องแรก แล้วคัดลอกรหัสลับมาวางช่องที่สอง
        3. กดบันทึก แล้วกด "ส่งแถวทดสอบ" ไปดูในชีตว่ามีแถวทดสอบขึ้นไหม
        4. ตั้งครั้งเดียวพอ ค่านี้ซิงก์ไปทุกเครื่องแบบเข้ารหัส

        ซิงก์ผ่าน GitHub

        เก็บข้อมูลที่เข้ารหัสแล้วไว้ใน repo ส่วนตัว (private) ของพี่ แล้วเปิดจากเครื่องไหนก็ได้

        วิธีสร้าง token
        1. สร้าง repo ใหม่บน GitHub ตั้งเป็น Private เช่นชื่อ elity-data
        2. ไปที่ GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
        3. Repository access: เลือก Only select repositories → เลือก elity-data
        4. Permissions → Contents: Read and write แล้วกด Generate
        5. คัดลอก token มาวางที่นี่ token อยู่เฉพาะเครื่องนี้และถูกเข้ารหัสไว้

        ความปลอดภัย

        บัญชี ·

        Elity เดิม: เปิดชีต Elity Brain → แท็บ Inbox → ไฟล์ → ดาวน์โหลด → CSV แล้วนำเข้าที่นี่

        ยังไม่ได้ปลดล็อก

        ข้อมูลเข้ารหัสด้วย AES-256-GCM กุญแจสร้างจากรหัสผ่านบนเครื่องนี้ (PBKDF2 600,000 รอบ) GitHub และ Anthropic ไม่เห็นรหัสผ่าน GitHub เก็บได้เฉพาะข้อมูลที่เข้ารหัสแล้ว

        ติดตั้งลงมือถือ

        Android (Chrome): เมนู ⋮ → ติดตั้งแอพ หรือ เพิ่มลงในหน้าจอหลัก

        iPhone (Safari): ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
